# Event Listing and Booking System

## Overview

This web application displays a list of events and allows users to book tickets. It includes user authentication, event management, and a booking system with a modal interface. The application is built using PHP and MySQL.

## Features

* **Event Listing:** Displays a paginated list of events, showing their names, dates, venues, and available seats.
* **Booking:** Allows users to book tickets for events with available seats.
* **User Authentication:** Includes login and logout functionality.
* **Booking History:** Allows users to view their booking history.
* **Event Management:** Provides an interface for adding new events.
* **Modal Interface:** Uses a modal to confirm bookings.
* **Dynamic Design**: Uses gradient backgrounds, blurred elements, and image integration for a visually appealing design.

## Technical Details

* **Language:** PHP
* **Database:** MySQL
* **Frontend:** HTML, CSS (with Tailwind CSS)
* **Pagination:** Implemented for event listings
* **Session Management:** Used for user authentication
* **Error Handling:** Includes error display for failed event loading
* **Layout**: Custom design with background gradients and centered content.

## Database Schema

The application uses the following database schema:

* **users:**
    * id (INT, primary key)
    * username (VARCHAR, unique)
    * password (VARCHAR)
    * created\_at (TIMESTAMP)
    * updated\_at (TIMESTAMP)
* **events:**
    * id (INT, primary key)
    * name (VARCHAR)
    * date (DATETIME)
    * venue (VARCHAR)
    * available\_seats (INT)
    * created\_at (TIMESTAMP)
    * updated\_at (TIMESTAMP)
* **bookings:**
    * id (INT, primary key)
    * user\_id (INT, foreign key referencing users.id)
    * event\_id (INT, foreign key referencing events.id)
    * booking\_time (TIMESTAMP)

## Files

* **index.php:** Main page displaying the event listing.
* **auth.php:** Handles user authentication (login, logout).
* **database.php:** Handles the database connection.
* **bookings\_history.php:** Displays the user's booking history.
* **add_event.php**: Allows admin users to add new events
* **book\_ticket.php:** Processes ticket bookings.
* **src/output.css:** Contains the CSS styles (generated by Tailwind CSS).

## Setup Instructions

1.  **Database Setup:**
    * Create a MySQL database named `ticket_booking`.
    * Create the `users`, `events`, and `bookings` tables using the provided SQL schema.
    * Populate the `events` table with initial data using the provided INSERT statements.
2.  **PHP Configuration:**
    * Ensure PHP is installed and configured with the necessary extensions (PDO, MySQL).
    * Configure the database connection in `database.php` with your database credentials.
3.  **Web Server Configuration:**
    * Place the application files in your web server's document root.
    * Ensure your web server is configured to run PHP files.
4.  **Access the Application:**
    * Open a web browser and navigate to the application's URL.

## Authentication

* Users can log in to the application using a username and password.  The `users` table should be pre-populated with user credentials.
* The `auth.php` file handles the login process and session management.  The `requireLogin()` function ensures that only logged-in users can access certain pages.
* A logout link is provided to terminate the user's session.

## Event Listing

* The `index.php` page displays a list of events retrieved from the `events` table.
* The events are paginated, with a default of 5 events per page.
* The page includes links to view booking history, log out, and add events (for administrators).
* The design uses a gradient background, a semi-transparent table, and styled buttons.

## Booking Tickets

* Users can book tickets for an event by clicking the "Book Ticket" button.
* The `book_ticket.php` script handles the booking process:
    * It verifies that the event has available seats.
    * It creates a new booking record in the `bookings` table.
    * It decrements the `available_seats` count in the `events` table.
* The booking confirmation is displayed in a modal window.

## Modal Interface

* The modal is implemented using HTML, CSS, and JavaScript.
* The CSS provides a fixed, centered, semi-transparent overlay.
* JavaScript is used to show and hide the modal dynamically.

## Design

* The application uses a visually appealing design with gradient backgrounds.
* The table displaying events has a semi-transparent background with a blur effect.
* Buttons are styled with custom colors, rounded corners, and hover effects.
* An image is included.
